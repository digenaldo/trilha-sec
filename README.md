# Trilha Sec

Guia gratuito, em português, para quem vem de engenharia de software migrar para segurança (DevSecOps, AppSec, Blue Team).

**Site:** https://ogatalars.github.io/trilha-sec/

## Parte 1 · Essencial

| # | Página |
|---|--------|
| 01 | Fundamentos |
| 02 | Redes e Linux |
| 03 | AppSec (OWASP, STRIDE) |
| 04 | DevSecOps (pipeline, supply chain) |
| 05 | Blue Team (SOC, Sigma, ATT&CK, resposta a incidentes) |
| 06 | Certificações (2026) |
| 07 | Laboratórios gratuitos e plano de 12 semanas |

Próximas partes: Nuvem e Kubernetes, Segurança de IA, Resposta a incidentes a fundo.

## Como funciona

HTML e CSS puros, sem build, sem JavaScript, servido pelo GitHub Pages. Custo zero. Para criar uma página nova, copie `_template.html` (o GitHub Pages não publica arquivos que começam com `_`).
